# 云函数部署指南（上线三件事）

> 适用：私人晨报助理（D:\Agent，12 个云函数，`cloudfunctions/` 下以实际目录为准）。
> 两条路径任选其一：**A. 脚本一键部署**（推荐，可重复执行）／ **B. 微信开发者工具手动上传**。

## 前置条件（两条路径共用）

1. **小程序 AppID**：`mp.weixin.qq.com` 用注册邮箱登录小程序后台 → 「管理 → 开发管理 → 开发设置」页首查看（当前 `project.config.json` 里的 `touristappid` 为游客占位，需替换为真实 AppID）。
2. **开通云开发**：小程序后台 → 「云开发」开通，记下**环境 ID**（形如 `cloud1-2gabcdef12345678`）。
3. **代码上传密钥**：「开发设置 → 小程序代码上传 → 密钥管理」→ 生成并下载 `.key` 密钥文件，保存到本机私有位置（**不要提交进仓库**）。若开启 IP 白名单，需把本机出口 IP 加入白名单。

## 路径 A：脚本一键部署（推荐）

1. 编辑项目根目录 `.env.local`（该文件是服务端本地文件，不会进小程序包），补齐三个 key：

   ```
   WX_APPID=wx1234567890abcdef
   WX_PRIVATE_KEY_PATH=D:/secrets/private.wx1234567890abcdef.key
   WX_CLOUD_ENV=cloud1-2gabcdef12345678
   ```

2. 运行：

   ```
   npm run deploy:cloud
   ```

3. 脚本行为：
   - 缺任一配置 → 打印中文引导并退出（码 2），不执行上传；
   - 配置齐全 → 逐个上传 `cloudfunctions/` 下的函数（remote 函数名 = 目录名），逐条打印成功/失败；
   - 有失败项 → 汇总失败函数与常见原因，退出码 1。

## 路径 B：微信开发者工具手动上传

1. 微信开发者工具打开项目（确认 `project.config.json` 的 `appid` 已替换为真实 AppID）。
2. 工具栏点「云开发」确认环境正确。
3. 左侧「云开发」面板 → 「云函数」列表 → 对每个函数目录：右键「上传并部署：云端安装依赖（不上传 node_modules）」。
4. 12 个函数全部显示「部署成功」后，在「云函数」列表逐一核对名称与环境。

## 常见报错

| 报错 | 原因与处理 |
|------|-----------|
| `Error: 无效的 private key` / 40125 | 密钥文件路径写错或文件损坏；重新下载密钥并核对 `WX_PRIVATE_KEY_PATH` 为绝对路径 |
| `Error: 无效的 appid` / 40013 | `WX_APPID` 有空格或仍是 `touristappid`；核对后台 AppID |
| `Error: IP 不在白名单` / 40164 | 开发设置里的 IP 白名单未含本机出口 IP；加入 IP 或临时关闭白名单 |
| `Error: 环境 ID 不存在` / 404 | `WX_CLOUD_ENV` 填的不是「环境 ID」而是环境名；回云开发控制台首页复制完整 ID |
| `函数上传成功但调用 404` | 函数未部署到当前调用环境；核对前端 `TARO_APP_CLOUD_ENV` 与上传环境一致 |
| 上传超时 | 网络代理干扰；关代理重试，或改走路径 B |

## 订阅消息模板 id 配置

同一模板 id 需要**两处配置**，必须填**同一个值**：

1. **前端（弹授权弹窗用）**：编辑 `src/config/subscribe.ts`，把模板 id 粘贴进 `SUBSCRIBE_TEMPLATE_ID` 常量。
   - 模板 id 获取：小程序后台 → 「功能 → 订阅消息」→「选用模板」→ 选「**一次性订阅**」类型模板 → 复制模板 id。
   - 空串 = 未配置：`promptSubscribe` 对空串直接 noop（不弹窗、不计入授权率统计），未配置不影响现有功能。
2. **云函数（7:30 定时推送下发用）**：给云函数环境 `getBriefing` 配置环境变量 `SUBSCRIBE_TEMPLATE_ID=<同一个模板 id>`（微信开发者工具 → 云开发控制台 → 云函数 → getBriefing → 配置 → 环境变量；或在 `deploy:cloud` 部署后于控制台补配）。

两处不一致的症状：前端授权成功但用户收不到推送（云函数拿不到正确模板 id）。
