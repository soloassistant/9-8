# Release Notes · 私人晨报助理

> 2026-09-27 · 对应增量战役 A–G + 竞品改进 16 项 · 递交范围：v1.4（记忆与排班增强 + 合规/体验/增长 16 项 + 偏好模块）

## 新增（v1.4 递交）
- 🧠 **记忆回灌（A）**：AI 助理对话前自动召回个人记忆注入上下文（云函数侧 MEMORY_RECALL_PROMPT 统一拼接），回复产生的新记忆自动写回；助理越用越懂你
- 🌐 **联网搜索扩面（B）**：聊天侧热点、购物两类意图自动触发联网搜索作答（NEWS_SEARCH_INTENT / webSearchReply 双通道），搜索结果标注来源；llm-proxy 端「无搜索工具」的限制声明同步移除
- 📅 **日历一键重排（C）**：日历页检测到冲突日程后可一键生成重排方案，逐项勾选确认后经 `apiApplyPlan` 落库（唯一写库通道，先提议后执行不变）
- 📊 **晨报负载条（D）**：按当日日程总时长（busyMinutes）在晨报透出忙碌程度，云函数 getBriefing 与前端 adaptive 同口径计算
- 🔍 **记忆溯源（E）**：AI 回复标注「本回复已参考 {n} 条记忆」，点开可查看引用了哪些记忆条目，不再黑箱
- ⏱️ **10 分钟缓冲排班（P1-F）**：排班候选优先保留与相邻事件 ≥10 分钟的间隙；时段全满找不到带间隙候选时，回退为无缓冲候选并在方案卡顶部明确标注（部分时段已排满），不再静默贴边
- 📈 **周复盘（G）**：按周汇总日程完成情况与作息规律，生成本周回顾（weeklyReview）
- ⚙️ **偏好模块（mb-prefs）**：用户偏好统一存储与读取，推送/内容形态类开关以此为单一数据源

## 竞品改进 16 项（v1.4）
- 🛡️ **合规（P0 · 5 项）**：AI 生成内容角标（热点页 AI 精选标识）、AI 精选关闭开关、晨报/热点免责页脚（common.disclaimer）、记忆隐私声明、时政内容源审计（详见 `docs/compliance-source-audit.md`）
- ✨ **体验（P1 · 6 项）**：热点条目「Why it matters」一句话解读、早报员「小晨」人设开场、推送偏好组（时间/频道组合设置）、订阅到期管理、资讯推荐原因透出、周末轻量版晨报
- 🌱 **增长（P2 · 5 项）**：晨报收尾冷知识、连续阅读徽章、晨报分享卡片（share-cover）、语音问候、未成年人模式

> 注：以上 v1.4 内容均已完成编码与静态自检（`.tools/selfcheck.js` 17 项），部分功能（推送、分享、语音、真机 TTS/ASR 降级行为）需真机验证后方可视为最终生效。

> 2026-09-12 · 对应 PRD v2.0 · 递交范围：v1.1（F20/F21/F22/F24 + 多语种学习平台 + 真实数据接入 + 固定域名）

## 这是什么
把散落在微信里的日程、待办和信息整理成一份可对话的私人晨报：转发消息给小程序，AI 自动提取并智能排班；每天早上收到晨报推送，用文字或按住说话与助理交互；日历页管好一天，热点页聚合全网资讯；顺路把多语种学习装进同一个助理。

## 已有核心功能（v1.0 基线）
- 5 Tab：晨报 / 收件箱 / 热点 / 日历 / 我的
- 收件箱：粘贴文字或截图 → AI 提取日程待办 → 冲突检测 → 逐条确认入库
- 晨报：今日日程 + 待办勾选 + 昨日收藏摘要；「🧠 深思」模式；工作助手（总结/要点/建议）
- 日历：月视图打点 + 单向写入手机系统日历
- 购物清单（兜底形态）：添加/勾购/手动比价记录 + AI 联网比价（标注来源与参考性）
- 全局搜索、浏览历史、主题换色、中英双语、头像更换、客服入口
- 合规：协议/隐私入口、注销（≤3步+二次确认）、AI 生成内容标注、授权管理

## 已知限制
- 手机号登录、微信支付：待企业主体资质与商户号（体验版为演示流程）
- 购物比价/代下单完整形态：待电商类目资质与平台 API（界面已标注"升级中"）
- 语音转写/TTS 需在小程序后台添加同声传译插件后才生效，未配置自动降级
- 学习社区动态暂存本机（种子示例展示氛围），云同步待接社区云库
- GitHub Pages 热点数据依赖 Actions 定时任务，最长 30 分钟延迟
