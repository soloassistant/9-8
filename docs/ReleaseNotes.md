# Release Notes · 私人晨报助理

> 2026-09-12 · 对应 PRD v2.0 · 递交范围：v1.1（F20/F21/F22/F24 + 多语种学习平台 + 真实数据接入 + 固定域名）

## 这是什么
把散落在微信里的日程、待办和信息整理成一份可对话的私人晨报：转发消息给小程序，AI 自动提取并智能排班；每天早上收到晨报推送，用文字或按住说话与助理交互；日历页管好一天，热点页聚合全网资讯；顺路把多语种学习装进同一个助理。

## 新增（v1.1 递交）
- 🎧 **音频晨报（F20）**：晨报一键 TTS 播报，长文本分块队列播放；微信端优先同声传译插件，H5 用 Web Speech API，均自动降级不阻断
- 🔀 **晨报自适应排序（F21）**：按日程密度、高优待办、行程冲突动态调整晨报区块顺序与开场白，爆满日日程前置
- 👍 **资讯反馈（F22）**：热点资讯支持 👍/👎 评价，本地持久化 + 云端同步（weapp），负反馈降权影响后续排序
- 📅 **AI 排班增强（F24）**：一句话批量/周期排班（「把周会固定到每周二上午」「下周一站会、周三评审、周五复盘」）直接落库；日历页新增本月忙闲统计（日程/待办/忙日/最忙星期）与忙闲热力着色
- 🌍 **多语种学习平台**：英语/日语/韩语 × 3 级 × 6 课分级课程；单词卡片互动学习（翻转/跟读）；学习进度追踪与连续打卡；个性化学习路径推荐（续学 > 间隔复习 > 新课）；成就徽章墙（8 枚数据驱动徽章）与打卡社区（发帖/点赞）
- 📡 **真实数据接入**：热点资讯流改为 RSS 全网聚合（36氪/少数派/爱范儿/虎嗅/澎湃/Bing News），每条标注来源；天气直连 Open-Meteo（免密钥）；H5 端分层加载（同源 API → Pages 静态 JSON → mock 降级），weapp 走云函数
- 🌐 **固定域名上线**：H5 产物部署 GitHub Pages（https://soloassistant.github.io/9-8/），GitHub Actions 每 30 分钟定时刷新热点静态数据；热点页支持关键词全网搜索（Bing News RSS + LLM 联网搜索）
- ✨ **开屏动画**：品牌橙全屏 Splash（logo 缩放淡入 + 标题上滑），1.6s 自动淡出，点击可跳过，双端通用

## 已有核心功能（v1.0 基线）
- 5 Tab：晨报 / 收件箱 / 热点 / 日历 / 我的
- 收件箱：粘贴文字或截图 → AI 提取日程待办 → 冲突检测 → 逐条确认入库
- 晨报：今日日程 + 待办勾选 + 昨日收藏摘要；「🧠 深思」模式；工作助手（总结/要点/建议）
- 日历：月视图打点 + 单向写入手机系统日历
- 购物清单（兜底形态）：添加/勾购/手动比价记录 + AI 联网比价（标注来源与参考性）
- 全局搜索、浏览历史、主题换色、中英双语、头像更换、客服入口
- 合规：协议/隐私入口、注销（≤3步+二次确认）、AI 生成内容标注、授权管理

## 已知限制
- 手机号登录、微信支付：待企业主体资质与商户号（体验版为演示流程）
- 购物比价/代下单完整形态：待电商类目资质与平台 API（界面已标注"升级中"）
- 语音转写/TTS 需在小程序后台添加同声传译插件后才生效，未配置自动降级
- 学习社区动态暂存本机（种子示例展示氛围），云同步待接社区云库
- GitHub Pages 热点数据依赖 Actions 定时任务，最长 30 分钟延迟
