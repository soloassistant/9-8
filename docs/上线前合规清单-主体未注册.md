## 二、🔴 协议与代码不符（5 处，全部已实测）

这一节是本轮最重要的产出。以下每一条都是「协议这么写 / 代码那么做」的**直接冲突**。

### 2.1 「账号信息：手机号码」—— 两端都不对 🔴

> 《隐私政策》一.1：「账号信息：**手机号码**（用于登录、账号安全与必要的服务通知）」
> 《用户服务协议》二.1：「本服务采用**手机号登录**」

✅ **已实测代码**：`src/services/cloudAuth.ts:37-40` 明确写着
> 「本页**只允许邮箱**……Web 应用不支持手机号/微信登录……手机号须走微信小程序那条线」

实际情况是：
- **H5 / 发布版** → 邮箱登录
- **微信小程序** → 微信 openid 身份（也不是手机号）

**手机号在这个产品里根本不是登录标识。** 而且反过来——**邮箱是 H5 唯一登录标识，
隐私政策全文一次都没提到邮箱**。

📌 **待办**：两处「手机号」改为按端说明；隐私政策补充邮箱条目。

### 2.2 「我们不收集……精确地理位置」—— 不实 🔴

> 《隐私政策》一.5：「我们不收集：你的微信聊天记录、通讯录、**精确地理位置**、相册」

✅ **已实测代码**：`src/services/location.ts:23`
```ts
const pos = await Taro.getLocation({ type: 'wgs84' })   // 精确经纬度
```

拿到的**就是精确经纬度**，政策说「不收集」与事实相反。

### 2.3 「坐标……不存储、不上传」—— 不实，且构成出境未告知 🔴

> 《隐私政策》四.1：「通过定位授权获得的坐标仅在本地实时换取城市名，**不存储、不上传**」

✅ **已实测代码**：`src/services/location.ts:25-27`
```ts
await fetch(`https://api.bigdatacloud.net/data/reverse-geocode-client?latitude=${latitude}&longitude=${longitude}...`)
```

坐标**确实发送给了 `api.bigdatacloud.net`**（第三方、境外服务）。
「不存储」大概率为真，「**不上传**」明确为假。

同时，政策四.1 还写「同步至中华人民共和国境内的服务器」——
**坐标出境这件事全程未提**，涉及 PIPL 第三十八、三十九条（向境外提供个人信息的条件与单独同意）。

⚠️ 我已同步修正了两处与代码矛盾的表述（本轮已改）：
- `src/app.config.ts` 微信授权弹层文案：原「坐标不存储」→ 现如实说明会发给第三方地图服务
- `src/services/location.ts` 注释：原「不落库不上传」→ 现标注为错误表述并说明正确事实

📌 **待办（产品决策，三选一）**：
1. **砍掉定位功能** —— 合规成本最低，且隐私政策两处都不用改
2. 换国内地图开放平台的逆地理编码 —— 回避出境，改文案
3. 保留但如实告知 + 在同意弹层里加**单独同意项**（PIPL 第二十三条）

### 2.4 「敏感信息（如手机号）」🔴

> 《隐私政策》七.2：「我们建立数据分类分级制度，敏感信息（如**手机号**）将严格限制访问范围」

同 2.1——敏感信息在 H5 端其实是**邮箱**，不是手机号。数据分类分级制度如果按「手机号」设计，
在 H5 上就保护错了对象。

### 2.5 《第三方 AI 服务说明》第 9 条「AI 处理不落库」⚠️

> 「AI 处理不落库——你的对话内容仅在调用第三方 API 时经其即时处理」

✅ **已复核**：对话内容本身确实不落库，但**同一批数据里有派生信息落库**：
`user_affinity`（类目偏好摘要）、`user_prefs`、`usage`（额度账本）。
措辞过宽，建议补一句「但会存储由你内容派生的偏好摘要与用量计数」。

## 三、控制台实测发现的真实问题

### 3.1 🔴 H5 的语音额度显示是 mock 假数据

✅ **已实测控制台**：
```
[Cloud] getUsage via cloud rpc failed, fallback to mock:
       Error: rpc-not-allowed:getUsage (H5 无微信上下文，且平台禁止客户端自传身份)
```

`getUsage` 不在 `src/services/dataSource.ts` 的 `RPC_ALLOWLIST`（仅 `webSearch/chat/extract`）内，
所以 H5 上取不到真实额度，直接落到 mock。

**用户看到的「本月语音免费额度 0/20 条」是假数字。** 用户真用了也不会正确递减。

⚠️ 更根本的问题：`cloudAuth.ts:243` 自己写着
> 「本应用数据库当前未建表，H5 的云端数据通路尚未接通」

**即 H5 端的云端数据通路整体未接通**——额度、跨设备同步、真实用量统计都不可用。
这是产品级缺口，不是 bug。

### 3.2 跨设备同步已熔断（按设计工作）✅

✅ `/api/user/sync` 返回 501 → 前端已停止轮询并给出明确文案「跨设备同步当前不可用，本地数据不受影响」。
**处理得当**，不算缺陷。
