本指引说明如何删除单条数据、如何导出数据、如何注销账号，以及删除的范围、时限与不可恢复后果。**注销不可恢复，请在操作前导出需要保留的数据。**

## 一、删除单条或局部数据

1.1 **日程/待办**：进入「日历」或收件箱，长按或点击条目菜单，选择删除；已同步的数据会在云端同步删除。
1.2 **记账**：进入「记账」页，滑动或点击条目删除；分类与预算可在设置中重置。
1.3 **收藏/购物清单/自选股/追踪词**：在对应页面逐条删除；删除最后一条时会显式推送空数组，避免云端旧数据回写。
1.4 **AI 对话与记忆**：在 AI 对话面板清空会话；在设置中清除 AI 记忆偏好。
1.5 **运动记录**：进入「运动」页，记录列表逐条删除；删除后本地与云端同步删除。
1.6 **浏览历史/通知历史**：在「我的」或通知中心选择清空。
1.7 **本地缓存**：在「偏好设置 — 数据保险箱」中可选择清空同步键数据；清除浏览器/小程序缓存也可清除本地数据，但**不影响云端数据**。

## 二、数据导出（建议在注销前完成）

2.1 **入口**：「偏好设置 — 数据保险箱 — 导出」。
2.2 **导出范围**：同步键白名单内的本地数据（如日程、待办、记账、收藏、购物清单、自选股、学习进度、运动记录、偏好设置等）。
2.3 **导出格式**：H5 下载 JSON 文件；微信小程序复制 JSON 文本到剪贴板，可自行粘贴保存。
2.4 **不包含**：服务端全部账号数据、订单与支付记录、支付机构数据、第三方服务商日志、未同步的本地临时数据。
2.5 如需更完整的个人信息副本，可通过客服提交申请；我们将在核实身份后 15 个工作日内提供（法律法规另有规定的除外）。

## 三、账号注销

### 3.1 网页端（H5）

步骤：
1. 登录后进入「我的」；
2. 找到「账号与合规」区域；
3. 点击「注销账号」；
4. 按提示输入注销确认词"注销"；
5. 确认后系统执行注销流程，并自动退出登录。

注销执行内容（当前实现）：
- 清空本地存储的业务数据；
- 清空云端同步数据（`user_kv` 中属于你的键值）；
- 尝试删除 `llm_events`、`feedback`、`client_errors` 中与当前凭证相关的记录（依赖 H5 直连云函数的部署状态；若未部署，需人工删除）；
- 退出登录状态，清除本地会话令牌。

### 3.2 微信小程序端

步骤：
1. 进入「我的」；
2. 点击「注销账号」；
3. 阅读提示并确认；
4. 系统调用 `deleteAccount` 云函数，按 openid 删除业务集合中的记录，并返回登录页。

删除范围（以云函数实际配置为准）：用户键值、日程/待办、收藏、记账、购物清单、运动记录、用量事件、反馈、崩溃日志、订单关联的业务数据等。

### 3.3 支付宝/抖音小程序端（如启用）

按对应端「我的 — 注销账号」入口执行；支付订单记录依法留存，不因注销删除。

### 3.4 各端差异提示

- **网页端注销不会删除平台侧的登录账号标识（邮箱/手机号）与认证记录**，因为 H5 账号体系不支持自助删除认证主体；如需彻底删除，请通过客服提交人工申请。
- **微信小程序端注销不会删除微信 openid 在微信侧的存在**，但我们会删除本服务云端与之关联的业务数据。
- 不同账号（邮箱账号、微信 openid 账号、支付宝/抖音账号）是独立账号，**注销一个不会注销其他账号**。

## 四、注销后的处理时限

4.1 在线自助注销通常在 **24 小时内**完成业务数据删除；云端备份与平台日志可能按平台周期延迟清除。
4.2 人工注销申请（如 H5 认证主体删除）自收到完整材料之日起 **15 个工作日内**完成核实与处理；复杂情形可延长并告知。
4.3 我们当前**未建立注销申请的在线工单队列与进度查询**；人工申请通过客服邮箱流转，可能出现延迟。**这是当前代码侧缺口**。

## 五、注销后仍可能保留的信息

5.1 依法必须留存的交易记录：依《中华人民共和国电子商务法》等规定，订单与交易信息自交易完成之日起保存不少于 **3 年**。
5.2 云服务商的平台级日志与备份：可能按平台策略在【待填写：备份周期】内继续存在；我们当前**没有独立的备份删除能力**，只能在平台能力范围内推动到期清除。
5.3 第三方服务商日志：天气（OpenMeteo）、地图（BigDataCloud）、AI 服务商、支付机构按其自身条款留存，我们无法代为删除。
5.4 匿名化或汇总统计：经不可逆匿名化、无法识别特定个人的统计数据可继续用于产品改进。
5.5 法律法规要求或司法机关要求保留的信息。

## 六、不可恢复项

6.1 注销后，以下内容**不可恢复**：
（1）账号本身及登录资格；
（2）云端同步的业务数据；
（3）订阅权益（未到期部分不退还，法定情形除外）；
（4）AI 记忆与个性化偏好；
（5）学习进度、社区内容、收藏与运动历史；
（6）已删除的本地数据。
6.2 注销后重新注册为**新账号**，不会恢复原数据；使用同一邮箱/手机号注册也不代表数据恢复。

## 七、注销前检查清单

- [ ] 已导出需要保留的数据（数据保险箱）
- [ ] 已确认没有未完成的退款/发票事项
- [ ] 已确认订阅到期时间与权益损失
- [ ] 已确认运动记录等敏感数据不再需要
- [ ] 已记录需要客服协助的事项（如 H5 认证主体删除）

## 八、特殊情形

8.1 **账号被盗**：请先联系客服冻结账号，再按客服指引办理注销，避免被他人恶意注销。
8.2 **未成年人账号**：应由监护人提出注销；我们核实后删除相关数据。
8.3 **已故用户账号**：近亲属可依法提出删除、更正或查阅请求，需提供死亡证明与亲属关系证明。
8.4 **争议中的账号**：涉及投诉、退款、司法调查的，我们可能暂缓注销直至处理完毕。
