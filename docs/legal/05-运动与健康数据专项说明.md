本说明是《隐私政策》的专项补充文件，适用于「运动」页面产生的运动与健康数据。**运动数据与轨迹可反映你的活动规律、居住/工作区域与身体状况，属于《个人信息保护法》第二十八条规定的敏感个人信息。我们仅在取得你的单独同意后处理。**

## 一、处理者与适用范围

1.1 处理者：【待填写：公司全称】。
1.2 适用范围：微信小程序、网页端（H5）「运动」页面的运动记录、周目标与统计展示。
1.3 与主政策的关系：本说明与《隐私政策》不一致的，就运动健康数据以本说明为准；本说明未尽事项适用《隐私政策》。

## 二、我们处理哪些数据

2.1 **你主动记录的运动数据**：
（1）记录开始时间、结束时间；
（2）运动时长；
（3）距离（米）；
（4）配速/速度（由上述数据计算）；
（5）轨迹采样点：采样时间、累计距离、经纬度（仅在你授予定位权限时）；
（6）数据来源标识（GPS 记录或仅计时）；
（7）你设置的每周目标公里数。

2.2 **我们不处理**：心率、血氧、血压、体温、血糖、睡眠分期、HRV、步频、步幅、卡路里（除按距离估算外）、月经周期、疾病史、用药记录、体检报告、可穿戴设备原始数据。

2.3 **我们不接入第三方运动平台账号**（如 Keep、Strava、Apple 健康、华为运动健康），**不存储任何第三方 OAuth 令牌或 refresh token**。当前版本未实现该能力；如未来开通，将单独告知并重新取得同意。

2.4 运动记录中的昵称、头像仅用于页面展示，来自你的账号资料，不属于运动数据本身。

## 三、处理目的与必要性

3.1 目的：
（1）记录与展示你的运动历史；
（2）计算周/月统计、连续记录、配速变化与目标完成度；
（3）在运动详情中绘制轨迹；
（4）跨设备同步与恢复（登录同一账号时）。

3.2 必要性：上述数据是实现运动记录功能所必需；不提供则无法生成运动记录与统计。
3.3 **不用于**：广告定向、保险定价、信用评估、健康风险评分、疾病预测、向第三方出售或交换。

## 四、合法性基础与单独同意

4.1 我们依据《个人信息保护法》第二十八条、第二十九条，就运动与健康数据处理取得你的**单独同意**。
4.2 同意在「运动」页面首次开始记录时以独立弹窗征求，文案包含处理目的、数据范围、保存方式、共享情况与撤回方式；**未同意不写入任何运动记录**。
4.3 同意记录包含：同意状态、同意版本号（当前 `v1-20261103`）、同意时间、设备端类型（h5 / weapp）。
4.4 **同意记录保存在设备本地，不随云端同步。** 因此你在新设备首次记录时需重新同意；这属于设备级授权，不代表其他设备已同意。
4.5 同意版本升级（如字段范围、目的变化）后，旧版本同意自动失效，需重新征求。

## 五、采集方式与定位

5.1 **仅在你主动点击"开始"后采集**，点击"结束"后停止。
5.2 轨迹依赖定位权限（微信小程序 `scope.userLocation`，H5 浏览器定位）。拒绝定位仍可记录时长与手动距离，但**不生成轨迹**。
5.3 当前**未实现后台持续定位**；离开运动页面或应用进入后台时，定位可能中断，轨迹可能不完整。
5.4 定位坐标仅用于当次运动轨迹与距离计算，**不用于天气、不做逆地理编码、不发送境外地图服务**。运动轨迹随记录保存，属于本说明的处理范围。
5.5 运动数据通过云同步白名单（`sportRuns`、`sport-goal-km`）同步至云端，按账号标识隔离；不同步同意记录本身。

## 六、存储、保存期限与安全

6.1 存储位置：设备本地存储 + 【待填写：云服务商名称】云数据库（存储地域【待填写：存储地域】）。
6.2 保存期限：至你逐条删除该记录、清空运动数据或注销账号；法律法规另有要求的除外。
6.3 安全措施：HTTPS 传输、按账号隔离访问控制、云端行级权限。
6.4 **当前未对运动数据实施应用层加密或字段级加密**，也未做轨迹脱敏/模糊化处理。数据安全主要依赖平台访问控制。我们将在上线前评估是否需要对轨迹做起点/终点模糊化或加密存储。

## 七、共享与委托处理

7.1 我们**不向任何第三方共享**运动与健康数据，不出售、不交换、不用于广告。
7.2 仅云服务商作为受托方存储数据，按我们的指令处理，不用于其自身目的。
7.3 运动轨迹**不发送**至 OpenMeteo、BigDataCloud 或其他境外服务。
7.4 如未来接入第三方运动平台或健康设备，将在传输前单独告知接收方、字段与目的，并重新取得单独同意。

## 八、你的权利与撤回

8.1 **撤回同意**：进入「运动」页面，点击授权状态行，选择"撤回运动数据授权"并确认。
8.2 **撤回的后果**：
（1）我们立即停止采集与写入新的运动记录；
（2）**已生成的记录保留**，不会静默删除（避免误删你的历史数据）；
（3）你可随时在记录列表中逐条删除，或在设置中清空运动数据；
（4）撤回不影响撤回前已进行的处理，也不影响其他功能。
8.3 **删除**：运动记录列表中每条记录提供删除入口；删除后本地与云端同步删除，不可恢复。
8.4 **查阅与更正**：你可在运动页查看全部记录与周目标，并修改目标；单条记录的时长/距离如需更正，可删除后重新记录。
8.5 **导出**：运动数据在「偏好设置 — 数据保险箱」的同步键范围内，可导出为 JSON（H5 下载 / 小程序复制）。
8.6 **注销**：注销账号将删除云端运动数据，详见《账号注销与数据删除指引》。

## 九、不构成医疗用途

9.1 运动记录与统计**不是医疗器械、不是健康监测服务、不提供医学诊断或治疗建议**。
9.2 配速、距离、卡路里估算可能存在误差；GPS 在隧道、高楼、树林中可能漂移。
9.3 如有身体不适、慢性疾病、孕期或运动康复需求，请咨询医生，不要依据本服务的数据作出健康决策。
9.4 我们不对因运动本身或依赖本服务数据导致的伤害承担责任，但依法应承担的责任除外。

10.2 我们当前未建立年龄核验机制，依赖用户与监护人声明。
