# P0 / P1 实施与验证记录（2026-10-14）

## 背景
上市标准检查（2026-10-14）给出的两条缺陷：
- **P0**：合规同意层只嵌在 `briefing` 页内，切到收件箱/热点/日历/我的 等其它 tab 或 AI 悬浮球时同意层不挂载 → 等于「可绕过同意直接使用」。必须把同意层上移到 App 外壳，并收口散落的 z-index 字面量。
- **P1**：AI 悬浮球在桌面端（≥500px）漂在视口右缘，与限宽居中的内容栏脱节；并要求同意层未通过时隐藏悬浮球。

## 改动

### P0 — 同意层上移 App 级 + z-index 单一来源
- 新增 `src/components/ConsentGate/index.tsx` + `index.module.scss`：把原 `briefing` 页内的同意层（遮罩 + 法务三文 ScrollView + 同意/暂不同意）整体搬到应用级。
- `src/app.tsx`：
  - 新增 `consentAgreed` 状态（`isH5 ? hasAgreedConsent() : true`）。
  - 渲染 `{!consentAgreed ? <ConsentGate onAgree={...}/> : null}`，且**未同意前不挂载 `<AiAssistant>`**（悬浮球被隐藏）。
  - `ConsentGate` 仅在 `!isLoginPage` 时渲染（登录页不弹）。
- `src/pages/briefing/index.tsx`：删除页内重复的同意状态与 JSX、删除 `@/data/legal` 导入。
- `src/pages/briefing/index.module.scss`：删除重复的 `.consent*` 样式。
- `src/app.scss`：新增 `:root` 统一 z-index 变量（唯一来源）：
  `--z-splash:9999 / --z-consent:2000 / --z-dialog:1000 / --z-fab:900 / --z-tabbar:700 / --z-voice:100`。
- 收口散落字面量：Splash(9999)、PermissionDialog(1000)、login overlay(1000→`var(--z-dialog)`)、
  login `.screen`(2000→`var(--z-consent)`)、AiAssistant FAB(900→`var(--z-fab)`)、
  mine/library 半屏遮罩(900→`var(--z-dialog)`，确保页面浮层盖过悬浮球)、
  briefing 输入栏(700→`var(--z-tabbar)`)、briefing habitToast(900→`var(--z-dialog)`)、
  VoiceButton(100→`var(--z-voice)`)。

### P1 — FAB 避让 + 桌面端跟随内容栏
- `src/components/AiAssistant/index.module.scss`：`.wrapper` 的 `z-index:900` → `var(--z-fab)`；
  新增 `@media (min-width: 500px) { .wrapper { right: calc(50% - 10rem); } }`，使悬浮球右缘对齐限宽居中的 20rem 内容栏（非视口右缘），与 `padding-right:24rpx` 同距。
- 同意层未通过时 `AiAssistant` 不挂载 → 悬浮球被隐藏（满足「同意/弹窗打开时隐藏 FAB」）。
