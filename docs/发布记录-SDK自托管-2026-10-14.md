> 工具：`workbuddy_sites_deploy`，`directory=D:\Agent\dist`，`language:"static"`，sandboxId 与链接不变。

## 修了什么

线上故障「cloud sdk unavailable / 登录服务连不上」的根因：云服务 SDK 从
`cdn.jsdelivr.net` 拉 IIFE，该 CDN 在中国大陆经常被墙 → 用户浏览器里
`window.WorkBuddyCloud` 永不定义 → `auth.errSdkUnavailable`。
2026-10-13 的「固定版本 + SRI」只解决了投毒/漂移，**没解决可达性**。

修法（一处收口）：把 dev 线那个具体构建（`0.1.3-dev.c090db7.202610050023`，
67666 B，sha384 `fjris8pRF0OENf…` 与 10-13 锁定的 CDN integrity 逐字节一致）
落地 `src/assets/wb-sdk.js`，`copy-assets.js` 随产物发到 `./assets/wb-sdk.js`，
`src/index.html` 改同源加载；同源文件去掉 integrity/crossorigin（避免将来
1 字节差异就拒绝执行）。不再依赖任何外部 CDN。
