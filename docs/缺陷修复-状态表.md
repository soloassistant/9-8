## 0. 约束（每批都适用）

- 一批一提交；`tsc --noEmit`、`eslint src/**/*.{ts,tsx}`、`npm run verify:all` 全绿才提交。
- 禁止 `git add -A` / `git add .`：只加精确路径；提交前核对 `git status --porcelain` 与 `git diff --cached`。
- 不假装部署 / 不假装申请 key：数据库、RLS、云函数、支付回调改动只写脚本与说明，标 ☁️。
- 统计数字必须来自真实数据；未开通能力必须显示“暂未开通”，不做假内容。
- 自动化选择器按稳定 className，不用 `data-testid`（Taro `Text` 不透传未知 props，见 `AGENTS.md §6.3`）。
- **定位是可选能力，不得作为任何功能的前置条件**（W 批次硬约束）：天气默认「手动选城市」；
  只有用户主动点「使用我的位置」才请求授权，拒绝/超时/无权限立即退回手动选城市；
  不反复弹授权、不卡首屏、不做 IP 定位。
- 本机 `git` 不在 PATH：用 `C:\Users\geral\.workbuddy\binaries\PortableGit\versions\1.3.0\cmd\git.exe`。
