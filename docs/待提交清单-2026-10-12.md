## 六、复现本清单

```bash
node .tools/git-status-lite.js          # 精确清单（内容级比对）
node .tools/git-status-lite.js --all    # 含全部 310 个未跟踪文件
```

**这个工具解决的是什么问题**：本机没有 git 命令行，但又必须知道「到底哪些文件改了」。
用 mtime/size 粗判会把「碰过但内容没变」的文件也算进去 —— 实测第一版报 80 个 modified，
其中 **44 个是纯假阳性**（仓库没写 `core.autocrlf`，但 Git-for-Windows 全局默认是 true，
检出时工作区被转成 CRLF，而 index 里存的是 LF blob，内容一样、哈希不同）。
改成同时比对「原样 / CRLF→LF / LF→CRLF」三种形态后，真实数字是 **36**。
