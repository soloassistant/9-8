## 1. 产品概述

### 1.1 一句话定位
一个 AI 私人助理，把用户零散转发的微信消息、截图、文章自动整理成**日程、待办、收藏**，并以**每日晨报**的形式主动推送，帮用户「从信息过载到从容一天」。

### 1.2 目标用户
- 微信重度使用者：工作/生活安排散落在群聊、私聊、截图里，经常漏事
- 有信息收藏习惯但从不回顾（「收藏夹吃灰」人群）
- 愿意为「省心」付费的个人用户

### 1.3 核心价值主张
1. **粘贴即整理**：转发/截图 → AI 提取日程待办，冲突自动检测并给排班方案
2. **晨报主动送达**：每天定时汇总今日日程、待办、昨日收藏精选、天气、资讯
3. **真实数据**：用户看到的一切数据均来自真实录入与真实聚合，不造演示数据
4. **零成本起步**：免费档可用核心功能；订阅解锁无限畅聊与增值能力

### 1.4 商业模式
- **免费 + 订阅**（早鸟折扣锁价）
- 免费档：语音 20 条/月、收藏 50 条、基础晨报、RSS 原始资讯
- 订阅档：语音不限次、收藏无限、LLM 提炼情报、主题分组、新功能优先

## 2. 名词定义

| 名词 | 定义 |
|---|---|
| 晨报 | 每日生成的个人日报：今日日程 + 待办 + 昨日收藏精选 + 今日情报（天气/资讯） |
| 收件箱 | 用户粘贴微信消息/截图的入口，AI 提取后生成草稿，勾选确认入库 |
| 情报（intel） | 晨报内嵌的天气 + 资讯条目，免费档为 RSS 原始条目，订阅档经 LLM 提炼 |
| AI 精选 | 热点页手动触发的资讯筛选：按兴趣画像从聚合新闻中挑 ≤10 条并给推荐理由 |
| 真实数据原则 | 用户可见数据必须来自真实录入/真实聚合；兜底数据必须明确标注「参考/降级」，禁止冒充实时或编造 |
| 用量真记账 | 免费额度（语音/收藏）按用户实际行为计数，展示与校验共用同一份计数 |

## 3. 产品架构

### 3.1 页面结构（5 Tab）
```
晨报（首页） ─ AI 对话/语音、今日时间线、情报、习惯守护
收件箱 ────── 粘贴/截图 → AI 提取 → 草稿确认入库；工作助手（总结/要点/建议）
热点 ──────── 12 源真实资讯聚合 + AI 精选 + 👍/👎 反馈
日历 ──────── 月视图忙闲、单日详情、手动添加日程、写入手机日历
我的 ──────── 头像/昵称、用量额度、订阅购买、主题/字号/语言、购物清单、注销
子页：收藏库、搜索、浏览历史、学习/口语练习、设置
```

### 3.2 数据分层（H5 预览端）
```
① 真实接口优先：同源 /api/*（静态服务 8137 聚合 RSS/热榜/天气/用户数据）
② 本地 AI：llm-proxy（8138，DeepSeek，key 只存服务端）
③ 失败降级：本地 mock 层（src/data/*.ts）——只做功能兜底，不造用户数据
④ 用户数据：Taro storage + 轻云同步（/api/user/sync，按 userId 隔离）
```

## 4. 功能需求

> 状态标记：✅ 已实现（H5 预览可验证）｜🔶 部分实现｜📋 规划中

### 4.1 晨报（首页）

| 编号 | 需求 | 验收标准 | 状态 |
|---|---|---|---|
| F01 | 每日晨报生成 | 读取统一日程/待办存储，自适应排序（爆满日日程前置、高优待办点名开场） | ✅ |
| F02 | 今日时间线 | 今日日程 + 今日到期待办合并排序展示，待办可勾选完成且**刷新后状态保留**（真实落库） | ✅ |
| F03 | 昨日收藏精选 | 展示收藏库最近 2 条真实摘要；无收藏时整个区块隐藏 | ✅ |
| F04 | 今日情报 | 免费档：真实天气（Open-Meteo）+ 3 条 RSS 原始资讯；失败降级不阻塞晨报；条目必须标注来源 | ✅ |
| F05 | AI 对话 | 文字/语音对话；深思模式（🧠）切换专属提示词；对话历史本地限长 60 条 | ✅ |
| F06 | 语音额度校验 | 免费档 20 条/月，超限弹订阅引导；用量为真实计数（发 1 条计 1 条） | ✅ |
| F07 | 习惯守护 | 今日日程可设为习惯，次日自动挪位；24h 内可撤销，还原失败保留重试入口 | ✅ |
| F08 | 阅读时长统计 | 阅读时长/区块曝光打卡，驱动连续阅读 streak | ✅ |

| 编号 | 约束 | 说明 |

## 7. 非功能需求

- **成本**：开发/演示阶段零成本——RSS/热榜/天气全部免 key；LLM 走国内备案 API（DeepSeek），key 仅存服务端
- **性能**：热点聚合 30min 缓存 + 来源健康度冷却（连续失败 2 次 → 30min 跳过）；LLM 结果缓存（精选 2h）
- **安全**：/api/chat、/api/user/* IP 限流；前端产物不含密钥
- **兼容**：微信基础库 2.17.1+（showModal editable）；H5 预览 Chrome/Edge
- **可验证**：check-all 体检 10 项（首页、热点源、天气、AI 回复、构建一致性），改动后必须全绿
